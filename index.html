Bases de Datos

UF01. Introducción y Diseño de Bases de Datos Relacionales

Analizar las necesidades de almacenamiento de información de una organización y realizar el diseño conceptual de la Base de Datos.

Horas: 30▶

UF02. Modelo Entidad-Relación y Normalización

Transformar el diseño conceptual en un modelo lógico relacional, definir les restricciones de integridad y aplicar el proceso de normalización hasta la 3ª Forma Normal.

Horas: 30▶

UF03. Lenguaje de Definición de Datos (DDL)

Crear, modificar y gestionar estructuras físicas de Bases de Datos en un SGBD utilizando sentencias del lenguaje de definición de datos (DDL y DML).

Horas: 40▶

UF04. Lenguaje de Manipulación de Datos (DML)

Manipular y consultar la información almacenada mediante sentencias DML complejas, incluyendo operaciones multitabla y agregaciones.

Horas: 50▶

UF05. Programación de objectos de BBDD (Triggers y Store Procedures)

Auditar el rendimento de les consultas executadas y programar lògica de negocio a nivel de servidor en el motor de base de datos.

Horas: 50▶
